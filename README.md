# 🐍 Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript**. Control the snake, collect food, increase your score, and try to beat your highest score without hitting the walls.

## ✨ Features

* 🎮 **Classic Gameplay** — Control the snake using the arrow keys.
* 🍎 **Food Collection** — Collect food to grow your score.
* 🏆 **High Score Tracking** — Save your high score using `localStorage`.
* ⏱️ **Game Timer** — Track how long you survive.
* 🔄 **Restart Functionality** — Restart the game and try again.
* 💀 **Game Over Screen** — The game ends when the snake hits a wall.
* 📊 **Live Score Updates** — Watch your score increase as you play.

## 🛠️ Technologies Used

* **HTML5** — Game structure and interface.
* **CSS3** — Styling and game board layout.
* **JavaScript (ES6+)** — Game logic, movement, collision detection, scoring, and timers.
* **DOM Manipulation** — Dynamically create and update game blocks.
* **Local Storage** — Persist the high score between sessions.

## 🎮 How to Play

| Key            | Action     |
| -------------- | ---------- |
| ⬆️ Arrow Up    | Move up    |
| ⬇️ Arrow Down  | Move down  |
| ⬅️ Arrow Left  | Move left  |
| ➡️ Arrow Right | Move right |

1. Click **Start** to begin.
2. Use the arrow keys to control the snake.
3. Collect food to earn points.
4. Avoid hitting the walls.
5. Try to beat your high score!
